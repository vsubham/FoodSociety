# Food Society

A responsive sample food-ordering UI. Browse and filter the menu, customize dishes, manage a bag, complete a demo checkout, and follow a simulated order status.

## Run it

Open `index.html` in a browser. The app uses local sample data and does not require a build step, account, or payment service. Food photography and web fonts load from Unsplash and Google Fonts.

## Order flow

1. Browse the menu by category or search.
2. Choose an item, size, quantity, and optional kitchen note.
3. Review the bag and adjust quantities.
4. Enter delivery details or choose pickup, then place a sample order.
5. View the confirmation and simulated preparation progress.

Checkout is for demonstration only; it does not send an order or process payment.
